核心洞察：IID loss 的 K×K 静态权重矩阵 对所有样本/类别一视同仁， 且梯度双向流动（target ↔ CLIP 同时更新）。 当 source accuracy 高或 CLIP 弱于 target 时，这会拖累 target 学习。 修复思路：用 source entropy 作为免费信号，在样本级和类别级自适应调节 IID 的对齐强度与方向。

四层自适应机制

层级 机制 驱动信号 效果
1 · 样本加权 sample_weights 调制 p_i_j 中各样本的外积贡献 source_score_bank (EMA 熵) 难样本（高熵）在联合分布中权重更大
2 · 方向控制 torch.where + detach leader 预测 逐样本 target_ent vs clip_ent 低熵方不吃梯度，高熵方单向对齐 leader
3 · bb / nnn 动态 bb 缩放 [1.0x, 1.5x]；nnn 缩放 [1.0x, 1.0+0.5·progress] batch 平均 source 熵 + known_mass 难 batch 增强已知类对齐；nnn 受训练进度门控防早期噪声
4 · bn 修复 w_aux + bn 替代硬编码 w_aux - 0.2 目前静态 bn=-0.2 bn 真正参与未知类非对角惩罚，可后续动态化

方向控制详解（核心）

对每个 selected sample，比较 target 与 CLIP 的熵。 target_leads → target detach，CLIP 学 target； !target_leads → CLIP detach，target 学 CLIP。 warmup 期 (iter < 80) 保持 target 全 detach 的旧行为。

权重矩阵区域与信号映射

区域 公式 驱动信号 当前状态
已知类对角 w_base = bb × ent_factor batch 平均 source 熵 → 难 batch 加强 ✅ 动态 [1.0x, 1.5x]
已知类非对角 0.45 无 ⬜ 静态（未来可基于 source 混淆矩阵）
未知类对角 w_aux = nnn × nnn_scale known_mass + 训练进度门控 ✅ 动态，upper bound 渐进放开
未知类非对角 w_aux + bn 跟随 nnn 变动 ✅ bn 已生效，可后续动态化
交叉区域 0.45 无 ⬜ 静态
未来方向： 已知类非对角权重 (0.45) 基于 source 混淆矩阵动态化 · 交叉区域权重动态化 · CLIP prompt 质量监控以精确控制 nnn 门控放开时机 · 更细粒度的 per-class 自适应替代统一的 batch 级缩放
